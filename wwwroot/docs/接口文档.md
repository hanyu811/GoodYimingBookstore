# BookStore API 接口文档（雏形）

## 1) 获取图书列表

- 路径：`GET /api/books`
- 查询参数：
  - `keyword`（可选）：书名或作者关键词
  - `category`（可选）：分类

### 示例

`GET /api/books?keyword=三体&category=科幻`

---

## 2) 获取单本图书

- 路径：`GET /api/books/{id}`

### 示例

`GET /api/books/1`

---

## 3) 新增图书

- 路径：`POST /api/books`
- 请求体（JSON）：

```json
{
  "title": "示例图书",
  "author": "作者",
  "category": "技术",
  "price": 88,
  "description": "图书简介",
  "coverUrl": "https://picsum.photos/seed/newbook/320/420"
}
```

---

## 4) 获取分类列表

- 路径：`GET /api/categories`

---

## 5) 获取文档链接

- 路径：`GET /api/docs`
- 返回：项目说明、接口文档、课程 PDF、Swagger 链接
