# BookStore 课程实践雏形

## 项目目标
本项目提供一个可运行的“书城”原型，包括：

- 首页图书展示页面
- 图书检索（关键词、分类）
- 最小可用的图书 API
- 文档链接入口

## 已实现内容

1. 网页入口：`/`（首页）
2. API 文档：`/swagger`
3. 业务接口前缀：`/api/*`
4. 项目文档入口：`/docs/*`
5. 已接入 SQL Server（EF Core）

## SQL Server / Navicat 使用说明

1. 在 Navicat 中连接你的 SQL Server 实例。
2. 新建数据库：`BookStoreDb`（或使用你自己的库名）。
3. 打开项目配置文件并修改连接串：
	- `appsettings.Development.json`
	- `appsettings.json`
4. 连接串示例（SQL 账号密码）：

	`Server=localhost;Database=BookStoreDb;User Id=sa;Password=你的密码;TrustServerCertificate=True;MultipleActiveResultSets=true`

5. 启动项目后，系统会自动建表并写入初始图书数据。

## 目录建议

- `wwwroot/index.html`：主页
- `wwwroot/app.js`：前端交互逻辑
- `wwwroot/styles.css`：页面样式
- `wwwroot/docs/接口文档.md`：接口说明
- `wwwroot/docs/课程实践任务.pdf`：课程 PDF（请手动放入）
